## المسار الحرج

```
الأساس ──▶ الهوية ──┬──▶ محرك القوالب ──┬──▶ Builder ──▶ نشر ──▶ RSVP ──▶ إطلاق
                     └──▶ الوسائط ────────┘
```

**محرك القوالب هو أطول مسار وأكثره خطراً.** يجب أن يبدأ مبكراً وأن يُثبت بثلاثة قوالب
مختلفة فعلاً قبل بناء الـ Builder فوقه. عيب في المحرك يُكتشف متأخراً = إعادة كتابة الـ Builder.

### إن ضاق الوقت — ترتيب التضحية

```
1. حذف حركات معقّدة   → أثر بصري بسيط، توفير أسبوع
2. تقليل إلى قالبين     → توفير 1.5 أسبوع، لكن يضعف اختبار المحرك ⚠️
3. تأجيل التحليلات      → توفير أسبوع، لا يؤثر على المستخدم مباشرة
4. تأجيل الإنجليزية     → توفير أسبوع ⚠️ لكن يصعب إضافتها لاحقاً (البنية تبقى جاهزة)
5. تأجيل Undo/Redo      → توفير 2 يوم

❌ ممنوع التضحية بـ:
   الأمان · اختبارات التفويض · النسخ الاحتياطي · تجريد EXIF
   أداء الصفحة العامة · دعم RTL
```

## نموذج التسليم

- **Trunk-based** مع فروع ميزات قصيرة العمر (< 3 أيام).
- Merge إلى `main` ⇒ نشر تلقائي إلى staging.
- نشر الإنتاج ببوابة يدوية.
- الميزات غير الجاهزة خلف **أعلام ميزات**.
- عرض أسبوعي على بيئة حقيقية (لا شرائح).
