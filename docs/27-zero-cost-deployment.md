# 27 — نشر المكدّس المجاني: ما يُنشأ، وبأي ترتيب

> **الحالة:** الكود جاهز ومُختبَر على المسارين. **لم يُزوَّد أي مورد بعد.**
> هذه الوثيقة هي الإجراء التشغيلي لمكدّس `$0` الذي أقرّته
> [ADR-0023](adr/0023-inline-media-processing-zero-cost.md)، بعد التحليل في
> [docs/25](25-zero-cost-launch.md) و[docs/26](26-zero-dollar-migration-analysis.md).
>
> المسار القديم لم يُحذف: [`render.yaml`](../render.yaml) وADR-0022 وعامل BullMQ
> كلّها قائمة وصالحة. الرجوع = `MEDIA_DISPATCH=queue` وإعادة نشر.

## ٢. الحسابات الخارجية المطلوبة — وهي وحدها ما لا أستطيع إنشاءه

| الخدمة | ما يلزم | بطاقة؟ |
|---|---|:---:|
| **Neon** | مشروع Postgres 16، ونسخ `DATABASE_URL` | لا |
| **Backblaze B2** | حاوية `zfaf-media`، ومفتاح تطبيق بصلاحية القراءة والكتابة عليها وحدها | لا |
| **Resend** | نطاق موثّق (SPF · DKIM · DMARC) ومفتاح API | لا |
| **Cloudflare** | المنطقة، ورمز API بصلاحية `Cache Purge` عليها وحدها | لا |
| **Sentry** | مشروع، ونسخ الـ DSN | لا |
| **Render** | حساب — والخدمة المجانية بلا بطاقة (§٦) | لا |

## ٣. الترتيب

### ٣.١ قاعدة البيانات أوّلًا

Neon → مشروع جديد → Postgres 16 → انسخ `DATABASE_URL` (المجمَّع/pooled).

ثم ضعه في **GitHub → Settings → Secrets → Actions** باسم
`FREE_STACK_DATABASE_URL`. لا يمرّ عبر محادثة ولا ملف.

### ٣.٢ الـ migrations قبل أي خدمة

```
Actions → Free stack — migrate → Run workflow
```

يطبّق الهجرات، ثم ينشر مكتبة القوالب، **ثم ينشرها مرّة ثانية ويثبت أن شيئًا لم
يتغيّر**. بلا هذه الخطوة يبقى جدول `templates` فارغًا و**لا تستطيع أي عميلة إنشاء
دعوة**.

### ٣.٣ التخزين

حاوية B2 باسم `zfaf-media`، ثم **سياسة CORS عليها — خطوة إلزامية** كما في
[docs/22 §٧-أ](22-deployment-render.md): الرفع يتمّ من متصفّح العميلة مباشرةً إلى
الحاوية، وبلا CORS يفشل بلا أثر في أي سجلّ على الإطلاق.

### ٣.٤ خدمة Render المجانية

من `infra/render/free.yaml`. القيم غير السرّية في المخطّط؛ والسرّية تُكتب في
اللوحة:

`DATABASE_URL` · `REDIS_URL` · `SESSION_SECRET` · `TOTP_ENCRYPTION_KEY` ·
`STORAGE_ENDPOINT` · `STORAGE_ACCESS_KEY_ID` · `STORAGE_SECRET_ACCESS_KEY` ·
`MAIL_RESEND_API_KEY` · `CDN_ZONE_ID` · `CDN_API_TOKEN` · `SENTRY_DSN` ·
`HEALTH_CHECK_TOKEN` · `TURNSTILE_SECRET_KEY` · **`CRON_SECRET`**

> `CRON_SECRET` ليس اختياريًا هنا: التطبيق **يرفض الإقلاع** على
> `MEDIA_DISPATCH=inline` بدونه، لأن مهمّة `redrive-media` هي وحدها ما يعوّض
> إعادة محاولة BullMQ. `openssl rand -base64 48`.

وعلى staging: تجاوَز `PUBLIC_BASE_URL` بعنوان `*.onrender.com` الحقيقي، وإلّا
أرسلت staging روابط تفعيل تشير إلى الإنتاج.

### ٣.٥ المؤقّت

```
cd infra/cloudflare/cron
npx wrangler deploy
npx wrangler secret put CRON_SECRET        # نفس القيمة التي في Render
```

ثلاثة جداول: الكنس والـredrive كل ساعة، انتهاء الصلاحية يوميًا، تفريغ المشاهدات
كل خمس دقائق. الفواصل مختارة مقابل حدّين مُقنَّنين لا ذوقًا: كل إطلاق يوقظ نسخة
Render (٧٥٠ ساعة شهريًا) ويستعلم Neon (١٠٠ ساعة-حوسبة).

> ⚠️ **لا تضع مؤقّت ping لإبقاء الموقع مستيقظًا.** يحرق الحصّتين معًا، والنتيجة
> تعليق كل شيء حتى الدورة التالية — أسوأ من إقلاع بارد.

### ٣.٦ Cloudflare أمام كل شيء

DNS، وTLS، وCDN أمام `/i/[slug]`، ورمز `Cache Purge` لمفتاح الإيقاف (D8.5).

## ٤. التحقّق بعد النشر

```
pnpm verify:deployment https://<the-url>
E2E_BASE_URL=https://<the-url> pnpm --filter @zfaf/web exec playwright test locale-routing.spec.ts
```

ثم يدويًا، بالترتيب: تسجيل حساب حقيقي ← وصول بريد التفعيل ← إنشاء دعوة ← **رفع
صورة ومراقبة كم تستغرق فعلًا** ← نشر ← فتح الرابط كضيف ← ردّ ← ظهور الردّ في
اللوحة.

**زمن الرفعة هو الرقم الذي يحكم على هذا المكدّس.** القياس هنا يقول ثانية معالج
واحدة لصورة ١٢ ميغابكسل، أي نحو عشر ثوانٍ على عُشر معالج — والرقم الحقيقي لا
يُعرف إلّا من النسخة نفسها.

## ٥. ما يُراقَب بعد الإطلاق

| المؤشّر | الحدّ | ماذا يعني تجاوزه |
|---|---|---|
| ساعات نسخة Render | ٧٥٠/شهر | خدمة موقوفة حتى الشهر التالي |
| ساعات حوسبة Neon | ١٠٠/شهر | قاعدة معلَّقة حتى الدورة التالية |
| تخزين Neon | ٠٫٥ غيغابايت | |
| تخزين B2 | ١٠ غيغابايت | |
| بريد Resend | ١٠٠/يوم · ٣٬٠٠٠/شهر | تسجيلات جديدة بلا رسالة تفعيل |
| أخطاء Sentry | ٥٬٠٠٠/شهر | يتوقّف الاستقبال، ولا تُحتسب تكلفة |
| `redrive-media` | يجب أن يكون صفرًا عادةً | رقم غير صفري متكرّر = الترميز يفشل بانتظام |

الأخير هو مؤشّر الصحّة الحقيقي لهذا المكدّس: `redriven` يساوي عدد الصور التي
كانت ستُفقد.

## ٦. ما لم يُختبر فعليًا بعد

| البند | الحالة |
|---|---|
| هل تقبل Render نشر Docker مجانًا بلا بطاقة؟ | **لم يُجرَّب على هذا الحساب** |
| زمن الرفع على ٠٫١ معالج | مُستنتَج من قياس على أنوية كاملة، لا مقيس على النسخة |
| Prisma عبر مجمّع اتصالات Neon | متوقّع أن يعمل بلا تعديل، وغير مُختبَر |
| B2 مع التوقيع المسبق وCORS | متوافق على الورق، وغير مُختبَر |
| `infra/cloudflare/cron` | **لا يدخل أي `tsconfig`، فلا يُفحص نوعيًا ولا يُلَنتَر.** يحتاج أنواع `wrangler` عند أول نشر |
| استعادة نقطة-زمنية | **غير موجودة في أي طبقة مجانية** |
