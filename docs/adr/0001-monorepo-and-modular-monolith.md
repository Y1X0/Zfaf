# ADR-0001 — Monorepo + Modular Monolith بدل Microservices

**الحالة:** ✅ Accepted · **اقتُرح:** 2026-08-16 · **اعتُمد:** 2026-08-16 · **القرار المرتبط:** #1

## السياق

نبني منصة SaaS بعدة أسطح (تسويق، لوحة تحكم، builder، صفحة عامة، إدارة، عمّال خلفيون)
وعدة نطاقات أعمال (دعوات، قوالب، وسائط، RSVP، فوترة، تحليلات).

القيود الحقيقية:
- فريق صغير جداً (1–3 مهندسين).
- المنتج **غير مثبت السوق** — قد تتغير المتطلبات جذرياً.
- الوصول للسوق بسرعة أهم من النقاء المعماري.
- أضخم حمل متوقع (قراءة الدعوة العامة) **مخدوم من CDN** لا من التطبيق.

## القرار

**Monorepo واحد (pnpm workspaces + Turborepo) يحتوي Modular Monolith بحدود صارمة**،
مع عملية `worker` منفصلة من اليوم الأول.

```
apps/     web · worker · (admin لاحقاً)
packages/ core · db · template-engine · invitation-renderer · ui · shared · config
```

**الحدود مفروضة بأدوات لا بالانضباط:**
- `dependency-cruiser` في CI يمنع الاستيراد المتقاطع بين الوحدات.
- قاعدة ESLint تمنع استيراد `PrismaClient` خارج `packages/db`.
- `packages/core` ممنوع عليه استيراد Next.js أو HTTP أو Prisma.

## البدائل المرفوضة

| البديل | لماذا رُفض |
|--------|------------|
| **Microservices** | تعقيد تشغيلي (نشر منسّق، تتبع موزّع، معاملات Saga، ×N تكلفة) بلا أي مكسب في حجمنا. الحاجة الوحيدة للتوسع المستقل يحلّها CDN. |
| **Polyrepo** | مزامنة الأنواع بين المستودعات كابوس، وتغيير يمسّ عدة حزم يصبح 4 PRs. |
| **Monolith بلا حدود** | يتحلل خلال أشهر إلى «كرة طين كبيرة» ويستحيل استخراج أي شيء لاحقاً. |

## العواقب

### إيجابية
- نشر واحد ذري · معاملات ACID مباشرة · تشخيص محلي بسيط · إعادة بناء شاملة (`refactor`) عبر الحزم بأمان النوع · أقل تكلفة.

### سلبية
- لا توسع مستقل للوحدات — **مقبول** لأن الحمل الأكبر على CDN.
- خطر تآكل الحدود مع الوقت — **مخفَّف** بالفرض الآلي في CI.
- تسلسل CI أطول قليلاً — مخفَّف بالتنفيذ المتأثر فقط (`turbo --filter`).

## محفّزات إعادة النظر

| المحفّز | الإجراء |
|---------|---------|
| الفريق > 8 مهندسين | فكّر في تقسيم فرق ملكية |
| الصفحة العامة > 500 req/s مستدام | استخرجها كخدمة قراءة |
| معالجة الوسائط تحتاج CPU مخصصاً | استخرج خدمة وسائط |
| احتياج API لعملاء خارجيين | لفّ `core` بـ Fastify/NestJS |

الاستخراج **ليس إعادة كتابة** — لأن `core` بلا تبعية إطار، ونقله يعني تغيير طبقة النقل فقط.
