# ADR-0025 — Media Private Redirect

**الحالة:** ✅ Accepted · **اقتُرح:** 2026-08-18 · **اعتُمد:** 2026-08-18

## السياق

الدعوات المنشورة تحتوي على صور معرضة علناً للزوار. الدلو (bucket) الذي يخزن الصور خاص، وليس علنياً.

المشكلة: **الزوار الذين لا يملكون حساباً لا يمكنهم تحميل الصور** — لا يملكون بيانات اعتماد التخزين ولا توقيع لطلب مباشر إلى R2.

## البدائل المرفوضة

| البديل | لماذا الرفض |
|--------|-----------|
| **جعل الدلو عاماً** | خطر أمني: ينكشف كل ملف، حتى الآن غير المُكتمل |
| **نقل الصور عند النشر إلى CDN علني** | تكلفة وتأخير — نسخ ملايين الصور يوم النشر |
| **خادم منفصل لتوزيع الصور** | تكلفة بنية تحتية إضافية، حمل CPU |
| **Resend أو خدمة توزيع خارجية** | تكلفة معاملات أو رسوم؛ يضيف عقدة معقدة |

## القرار

**تطبيق مسار `/m/[...key]` يصدّر توقيعات B2 قصيرة الأجل عبر 302 redirct**،
دون نقل أي بايتات عبر خادم التطبيق. المتصفح يتابع الإعادة مباشرة إلى R2.

### الآلية

1. **الضيف ينقر على صورة** في صفحة دعوة منشورة.
2. **المتصفح يطلب** `/m/media/<uuid>/<uuid>/<uuid>/w256.jpg`
3. **المسار يتحقق** من النمط: فقط مفاتيح عرض مُصغّرة (`w<digits>`) — رفض `original.bin`
4. **التطبيق يستدعي** `createSignedDownloadUrl` مع TTL = 1 ساعة
5. **الرد 302** برابط موقّع قصير الأجل (أقل من TTL التوقيع)
6. **المتصفح يتابع** — والتحميل من R2 يتخطى التطبيق تماماً

### النمط المسموح

```
media/<uuid>/<uuid>/<uuid>/w\d+.<ext>
```

أمثلة:
- ✅ `media/abc123.../def456.../ghi789.../w256.jpg` — عرض مُصغّر
- ✅ `media/abc123.../def456.../ghi789.../w512.webp` — صيغة بديلة
- ❌ `media/abc123.../def456.../ghi789.../original.bin` — ملف خام (مرفوض)
- ❌ `media/abc123.../def456.../ghi789.../w` — بدون امتداد (مرفوض)

## المقارنة الاقتصادية

| الجانب | التكلفة |
|-------|--------|
| **التطبيق (Render 0.1 CPU)** | بلا تأثير — لا يوجد نقل بايتات |
| **R2 (التخزين + التوقيع)** | عملي — نفس الدول الذي نستخدمه الآن |
| **بنية تحتية إضافية** | **صفر** — لا خوادم جديدة |
| **الإجمالي الإضافي** | **$0** |

## العواقب

### إيجابية
- **صفر تكلفة** — بلا تغيير في الفاتورة.
- **صفر عبء CPU** — التطبيق لا ينقل بايتات.
- **أمان محافظ** — المفاتيح الخام (مثل `original.bin`) محمية.
- **خبرة سريعة** — متصفح الضيف يحمّل من R2 مباشرة، بلا وسيط.
- **طفرات مستقبلاً** — يمكن إضافة التتبع أو الحد من معدل النقل إذا لزم الأمر.

### سلبية
- المتصفح يتعامل مع نطاق مختلف (R2) — كوكيز الجلسة تبقى على النطاق الأساسي ✓
- التوقيع لمدة 1 ساعة: رابط مشترك مع الآخرين يبقى صالحاً طالما الساعة لم تنقضِ — مقبول للمشاهدة الجماعية.

## محفّزات إعادة النظر

- إذا اضطررنا لتتبع دقيق لتحميلات الضيوف (يمكن إضافة webhook إلى R2).
- إذا أصبح تحميل الملفات الخام (الأصلية) للقائمة المسموحة (ندرة).
- إذا أراد عميل جديد تحكّماً أدقّ في الأذونات (يحتاج سياق جديد).
